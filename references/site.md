# 阶段B：静态百科与SVG

先读阶段A交接、代表性条目、进度和过期条目清单。资料范围以交接和数据库为准；局部样本明确标注范围。待查或撤回的说法不写成确定设定，过期正文先复核。

从作品特征提炼配色、字体层级、线条和图案，默认以SVG和CSS制作视觉。装饰纹样可以原创；人物外貌、地图关系、阵营徽记等具体内容需要原作依据，推测性设计注明性质。避免用装饰暗示未经证实的世界观。

先做首页与代表性条目形成视觉样式，再复用到其他页面。以百科查阅为中心：可发现的分类、中文搜索、条目互链、页内目录、清晰的出处与相关条目。人物页同时容纳档案和连贯经历，表格与正文各司其职；栏目按资料多少调整，不强塞空模板。

使用当前环境适合静态输出的工具。优先本地可浏览、易修改的产物，保留SVG源文件和构建方式。按用户当前范围完成本地站；云端部署、注册、协作功能留待用户提出。

完成后检查窄屏与桌面阅读、长标题与长文、键盘操作、搜索和互链；用实际条目检查，不能只看空壳布局。SVG使用可读标题或适当的装饰语义，正文保持足够对比度。

交付静态站、源文件、运行或构建方法及资料覆盖说明。默认不随站点发布整本原文或完整数据库；公开页面仅包含所需条目、必要短引文及出处。发现事实错误时先改数据库，再刷新页面。
