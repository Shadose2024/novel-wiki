# 判断 → 初步确定 → 事实

这是百科的编辑采用规则。原文明确表达、经过忠实转述的判断，可随阅读推进获得确认。第一轮不要求每一条人物介绍都得到第二个独立来源证明。

## 三个阶段

| 标签 | 时机与处理 |
|---|---|
| 判断 | 首次提取，保留说话人、原文位置及原有语气；先核对提取内容有没有增添、夸大或误读。 |
| 初步确定 | 默认读完随后10个目录章节，或相关大情节已经收束，再复核相关记录；没有未解决的冲突，且这条判断适合按事实采用，即升级。 |
| 事实 | 读完当前来源版本的全文后，集中复核仍为初步确定的记录；没有后文改写或反转的，批量认定为百科采用的事实，正文去掉初步确定标签。 |

“10章”是安排复核的默认窗口。阅读进度达到窗口只触发复核，不单靠章节计数修改标签；剧情收束允许提前复核。书末不足10章时，可按相关情节结束做初步确认，再参与全文收尾。原文直接给出确定证据的内容，也可经核对直接作为事实采用。

## 适用范围

- 普通人物介绍、技术说明、身份说明和事件判断：原文有相应表达，且复核后无反证，可以采用。
- 未解疑问、已知冲突、明确的谎言或传闻、带明显怀疑的判断：保留在待处理清单，先解决问题；没有反转本身不能填上原文未给出的答案。
- 提取时擅自增加的细节或提高的确定程度：先修正提取，不通过等待后文来确认。例如“搞定”不能自行扩大为“已经建成并正式投用”。
- 计划或预期：可以确认“某人提出了这一计划”，但其发生状态仍是计划。后文是否实施，另据后文记录。
- 人物阶段状态：后文改变不一定意味着早期错误。早期身份、能力仍可在其时间范围内作为事实保留；真正的揭露或纠正再建立纠正关系。

不需要让最终条目满是“某某声称”。对已被采用的内容正常陈述，引用仍可回查最初的原文、说话人和确认过程。

## 数据库与执行

结构由 `../scripts/schema.sql` 加 `../scripts/confirmation.sql` 组成。新增 `confirmation_status`（采用状态）、`confirmation_basis`（窗口/剧情收束/全文/直接证据）、`confirmed_through`（已核对到哪章）、`confirmation_note`（复核理由）。

`source_status` 继续记载资料来自叙述、人物说法还是整理者推断；升级事实不覆盖这一字段。`review_status` 记录是否核对过提取内容。`modality` 保存已经发生、计划、一般描述等状态，升级也不改写它。

数据库中的 `fact` 保留为可审计状态；正文不显示判断或初步确定标签。确认记录进入既有修改历史。内容或证据修改后恢复为判断，重新复核；被否定或尚有冲突时使用 rejected/disputed。

复核由执行skill的模型完成；脚本检查阅读范围、版本和已登记冲突，并事务化保存，不自行理解小说中的真假。迁移后的已有记录从判断开始，不批量追认为已核实事实。

确认操作仍通过 `wiki.py --db 作品.sqlite apply` 提交，可以在一份JSON的 `operations` 中放多条，实现全文结束时集中确认。单条示例：

```json
{
  "reason": "当前版本全文结束后的集中复核",
  "editor": "Codex",
  "operations": [
    {
      "table": "record",
      "id": "需要确认的记录ID",
      "expected_version": 2,
      "set": {},
      "confirmation": {
        "status": "fact",
        "basis": "full_text",
        "through_chapter": "全文末章ID",
        "faithful_to_source": true,
        "no_unresolved_conflict": true,
        "eligible": true,
        "note": "复核记录的具体范围、结论和适用时间。"
      }
    }
  ]
}
```

初步确认使用 `status=provisional`，`basis=window` 或 `arc_end`；后者还需提供 `arc_note`，说明哪段剧情已收束。先通过已有编辑入口把核过原文的记录标记为 agent_checked/human_checked，然后提交确认。

`source_scope.total_chapters` 来自导入时的完整目录。全文确认要求目录范围内的章节均已读取，或明确记载排除理由；导入三章样本不能被视为全书完成。书籍补章或更换来源版本后，相关确认需要重新复核。
